Timbient Modules

A pixelated, modular patch-bay playground for ambient and experimental music: sequencers, voices and effects to patch together.

What it is

Where this is different from a DAW is that there isn't just one BPM, and you don't need to input specific notes. Everything can be clock-synced together (and there's a note-entry tracker module), but the idea is that separate voices can have completely different timings from each other, and you choose a scale, key and range in which notes are generated.

It's made to run well on older hardware too, including 32-bit Windows machines.

Installing

Mac (Intel and Apple Silicon, macOS 10.13 or later): unzip, drag Timbient Modules.app into Applications, then run this once in Terminal (the app isn't signed with an Apple developer certificate):

xattr -cr "/Applications/Timbient Modules.app"

Windows: unzip and run Timbient Modules.exe. If Windows warns, click More info, then Run anyway.

In your browser

The web player plays sessions saved from the app (with their sounds) on a phone, a tablet or any computer, with nothing to install. It plays sessions; changes are made in the app.

On a phone it can be installed from the browser's menu, and then opens full screen like an app.
